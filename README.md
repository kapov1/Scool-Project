# NetPath Interactive — v3 fix

Обновлённая версия школьного проекта «Компьютерные сети». В этой сборке исправлена компоновка схем девяти этапов.

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python3 -m http.server 5500 --bind 127.0.0.1
```

Затем откройте в браузере `http://127.0.0.1:5500`.

## Что исправлено в v3 fix

- В схемах обмена сообщениями больше нет вертикальных lifeline-линий.
- Каждое сообщение показано отдельной горизонтальной строкой: карточка отправителя → стрелка с подписью → карточка получателя.
- Карточки участников стали крупнее; в трёхсторонних схемах расстояния рассчитаны так, чтобы подписи сообщений помещались между участниками.
- Стрелки соединяются непосредственно с границами карточек.
- Названия внутри карточек и подписи сообщений переносятся по фактической ширине текста, измеряемой браузером, а не по приблизительному числу символов.
- Длинные подписи ограничены шириной свободного промежутка и переносятся на две строки при необходимости.
- Схемы маршрутизации и отрисовки страницы упрощены: убраны необязательные подписи над короткими стрелками, увеличены карточки.
- TLS-схема показывает ClientHello, ServerHello/EncryptedExtensions, Certificate/CertificateVerify, Finished сервера и Finished клиента.
